Featured Project

What I Built

PoliceOSINT v1.0

AI-Powered Cyber Crime Investigation & Intelligence Platform

Next.js 14 FastAPI Celery Redis PostgreSQL Docker Groq/Llama-3.3-70b Nginx

The Problem

Cyber fraud in India has led to losses of thousands of crores annually. Traditional investigation methods depend on victim complaints and manual data collection, leading to delayed detection and missed opportunities for preventive action.

The Solution

PoliceOSINT automates the collection, analysis, and correlation of cyber threat intelligence from 50+ public sources including DuckDuckGo, Google News RSS, Reddit, Twitter/X, and Telegram channels. By combining OSINT collection with Groq/Llama-3.3-70b generative AI, the platform transforms raw digital intelligence into actionable, court-ready reports.

System Architecture

Data Ingestion Layer

  • DuckDuckGo HTML scraper — keyword-based scam search
  • Google News RSS — real-time scam campaign articles
  • Reddit API — r/scams, r/india, r/cybersecurity
  • Twitter/Nitter scraper — investment fraud tweets
  • Telegram monitor — real-time message extraction via Telethon
  • Government feeds — CERT-In and Cybercrime.gov.in advisories

AI Analysis Pipeline

  • Stage 1: Heuristic regex engine scans for IOCs (UPI IDs, phone numbers, crypto wallets, URLs)
  • Stage 2: Groq/Llama-3.3-70b acts as digital forensic assistant
  • Drafts FIR notes, recommends IPC/IT Act sections
  • Explains threat patterns and guides investigation steps
  • Assigns preliminary risk scores (0–100)

10+ OSINT Investigation Modules

  • Identity Intel: Email breach, username enumeration, phone lookup
  • IP Intelligence: GeoIP, ASN, ISP, VirusTotal check, TOR/VPN detection
  • Domain Analysis: WHOIS, DNS, SSL, subdomain enumeration
  • UPI Fraud: Risk scoring, fraud pattern detection, mule account indicators
  • Cryptocurrency: BTC/ETH/TRX tracing, mixer detection, cluster analysis, Indian VASP contacts
  • Threat Intelligence: MITRE ATT&CK mapping, IOC correlation
  • Dark Web: Ahmia search, credential leak monitoring
  • GEOINT: Reverse geocoding, IP-to-location mapping
  • Social Media: Cross-platform username search, profile risk scoring
  • Media Forensics: EXIF extraction, reverse image search, deepfake scoring

Cryptocurrency Investigation Engine

  • Accepts BTC, ETH, and TRX wallet addresses with auto-chain detection
  • Extracts full transaction history via Blockchain, Etherscan, and TronScan
  • Mixer/tumbler detection — checks against known mixing services and behavioral heuristics
  • Cluster analysis — maps related wallet addresses and hop count to exchanges
  • Crime risk scoring combining mixer probability, cluster size, and transaction patterns
  • Indian VASP (Virtual Asset Service Provider) LEA contacts for WazirX, CoinDCX, ZebPay, CoinSwitch
  • Generates LEA notice templates for Section 91 CrPC requests to exchanges

Dashboard & Visualization Layer

  • Real-time command dashboard — active cases, critical cases, financial losses tracked
  • Internet Scam Intelligence row — live counts of flagged scams, high-risk IOCs, category breakdown
  • Entity Relationship Graph — force-directed visualization mapping connections between suspects, UPI IDs, wallets, domains, IPs, and social profiles
  • UPI Fraud Cluster — visual mule account network with freeze recommendations
  • Cross-Platform Correlation — detects same scammer operating across Telegram, Twitter, Instagram, and dark web

IPDR Analyzer

  • Accepts PDF uploads of court-ordered IPDR documents issued under Section 91 CrPC
  • Extracts all IPv4 and IPv6 addresses using regex pattern matching
  • Skips private, loopback, and reserved IP ranges automatically
  • Enriches all public IPs with GeoIP, ISP, ASN, city, and country via IPinfo
  • Detects TOR exit nodes, VPN services, and proxy servers
  • Assigns risk scores and highlights foreign IPs
  • Action buttons: full investigation link, Google Maps location, abuse contact email

Digital Evidence Management

  • File upload with automatic SHA256 and MD5 hash computation
  • Exhibit numbering (EX-YYYYMMDD-HHMMSS format)
  • EXIF metadata extraction from uploaded images including GPS coordinates
  • Integrity verification — re-hash at any time to confirm evidence has not been tampered
  • Complete chain of custody with officer badge number, timestamp, and action log
  • Evidence sealing for court submission

Report Generation

  • FIR Support Report: Case details, IPC/IT Act sections, digital evidence checklist, Section 91 CrPC notice templates, escalation requirements
  • Intelligence Report: All OSINT findings, risk scores, sources queried, investigation summary
  • Suspect Profile: Known digital identifiers, risk assessment, modus operandi, grounds for arrest
  • Generated using ReportLab with signature blocks for three officers

Access Control & Audit

  • 8 role levels: super_admin → commissioner → sp → inspector → sub_inspector → constable → analyst → trainee
  • Every action logged — logins, case creation, evidence upload, investigation runs, report generation
  • Complete audit trail with officer badge number, timestamp, IP address, and status
